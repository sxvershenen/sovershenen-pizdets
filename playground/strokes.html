Метод и ограничения

Каждый сегмент контура проверен в пяти точках. Замер идёт по нормали сквозь заливку до первого выхода наружу. Если у выхода нет почти параллельной встречной границы, проба отбрасывается. Границы пронумерованы внутри конкретного глифа. Колонки «При 125%» и «Δ» сравнивают медианы одной пары границ и одного направления при том же весе. Прочерк означает, что такой пары при 125% нет. Обратные направления сохраняются раздельно. На рисунке показан один из лучей выбранной группы. Минимум и максимум относятся ко всем принятым пробам группы.

Эталоны для всех глифов — QEUTPHF при тех же координатах осей. Для каждого направления взят диапазон медиан семи эталонов, где они измеримы. Прямые диагонали сравниваются с горизонталями этих букв. Для дуг есть отдельные эталоны по направлению касательной. Синим выделены тонкие участки, красным — толстые. Допуск прямых — 7,5% средней эталонной толщины, минимум 2 единицы. Для дуг и коротких замеров допуск удвоен, минимум 4 единицы. Это порог отбора для просмотра. Контраст округлений, акценты, знаки валют, индексы и орнаменты могут отличаться по рисунку.

В списке знак отклонения показывает выход медианы за границу допуска по надёжной прямой паре минимум с двумя пробами. Фильтр локальных отклонений учитывает также минимум и максимум. Участки без надёжной пары перечислены отдельно. Для Жж взят профиль формы 48 / 50 / 50. Единицы измерения — 1/1000 em.
