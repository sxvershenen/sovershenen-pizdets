# Sovershenen Pizdets Lab

Сравнение «a/а» доступно по пути `/a/` после запуска сервера. Высота 0 и толщина 110% воспроизводят профиль сборки 4.001. «Сбросить» возвращает эти значения.

Из этой папки запусти `python -m pip install fonttools==4.68.0`, затем `python server.py --open`. Нужен Python 3.10+. Лаборатория открывается на `127.0.0.1:8731`.

- **Оси** — размер образца в CSS px, вес 100–900, ширина 100–175, старт 107%. «Релиз 3.17» позволяет сравнить исходный диапазон 100–125.
- **Сбросить настройки** — восстановить стартовый профиль целиком, включая образец, оси, референсы и трекинг.
- **Для чтения** — 12 отрывков на русском и английском, включая смешанный текст. «Капс» меняет регистр в образце, абзаце, размерном ряду и красных слоях. Выбор сохраняется отдельно от короткого образца. Оси и трекинг общие.
- **Референсы** — четыре независимых красных слоя. Оригинал 3.17 следует ширине до 125%. Слои доступны в образце, тексте для чтения и размерном ряду. Оригинал доступен и в инспекторе штрихов. По умолчанию одинаковый кегль. Опция «Совместить высоту прописных» масштабирует референсы по cap height. Для MicroTechnic используется метрика установленного Extended Bold. Запасной способ подключения — выбрать его файл.
- **Ж / ж** — вылет полок, высота развилки (наклон ножек), масса диагоналей. Базовая форма — вылет 48, наклон 50, толщина 50. Нейтральная форма повторяет Жж из 3.17 до 125%. Дальше расширяются собственные ветви Жж с сохранением толщины у конца и стыка. Для проверки есть пресет «Жж / Кк».
- **У** — по умолчанию низкий стык и толщина штрихов 80. Доступны три рисунка и плавная настройка обеих осей. Действуют после 125%. Выбор закрепляется при экспорте.
- **Трекинг** — 2–16 точек. Размеры 6–200 целых CSS px. Значение в процентах em. При 5,4% прибавка равна 0,054 em. Линейная интерполяция, крайние значения удерживаются. Начальная кривая — 8 px → 5,4%, 12 px → 3,8%, 24 px → 2%, 48 px → 0%. Изменения сохраняются в этом браузере.
- **Скачать TTF** — сохраняет выбранные формы Жж и У, полный диапазон wght и wdth, кривую opsz. Метрики меняются внутри шрифта. При использовании держать CSS letter-spacing в normal, если дополнительный трекинг не нужен.
- **Оптический размер** — веб-калибровка 1:1: числовой opsz равен CSS px. Проверено в Chrome на этом Mac. В приложениях с размером в пунктах при необходимости задавать opsz вручную.

## Источники и сборка

- Основа — [Sovershenen Pizdets 3.17, 05db434](https://github.com/sxvershenen/sovershenen-pizdets/tree/05db43440ff8081546ff6bc9b429327ca8ebdd21). Сборка мастеров и осей Жж — `font/build.py`, построение стыков и компенсация толщин — `font/letterforms.py`, `font/strokes.py`, `font/capitals.py`, аргументы — каталог `sources` из этого коммита и выходной TTF. Требует fontmake 3.12.2.
- `font/lab.ttf` — мастер плейграунда, `optical.py` строит ось opsz и закрепляет настройки Жж при экспорте.
- Roboto и Roboto Flex — [google/fonts](https://github.com/google/fonts/tree/main/ofl). Лицензии в `assets/*-OFL.txt`, лицензия основы в `font/OFL.txt`.
- MicroTechnic Extended Bold подключается с компьютера пользователя.

Аудит — `stroke-audit.html`. 975 глифов, 35 положений осей. Толщина измерена по нормали в единицах em/1000. Повторить замер — `python font/audit.py font/lab.ttf readings.json`, зависимости fontTools и numpy.

Подробный аудит — `strokes.html`, данные — `stroke-data/`. 975 глифов × 10 весов × 7 ширин. Пересчёт — `python font/stroke_review.py font/lab.ttf stroke-data` (numpy, fontTools, uharfbuzz). Эталоны — QEUTPHF для всех глифов, с учётом подстановки Q по весу. Нативные W, я, У/R/Я, k/к, у/y и Д сохраняют рисунок 3.17 до wdth 125 включительно. Xx/Хх раскрывают центральную перемычку после wdth 125. У a/e/o/g/c и кириллических а/е/о/с/ё/э ширина рисунка плавно сходится к ширине e на 175%. Прибавка для e взята у n при том же весе. Сохраняется 20% исходной разницы в единицах шрифта. В паре ку верхний просвет ограничивает кернинг. Пресет «Круглые и ку» показывает обе группы в строке. Пресеты «Перед Д» и «Ножки» показывают пары и соединения при текущих осях.

Визуальный аудит слепых участков — `junctions/index.html`. Плашка сравнения использует исходные глифы для воспроизведения дефектов; ссылки ведут на текущий шрифт в `strokes.html`.

«Ритм слов» — поближе, ЗАКАЗ, ЗВЯКНУЛО, ЮЖ, WAVE, моя. Контроль 500–600 wght. Кернинг бл, иж, ЗА, УЛ меняется после wdth 125.
